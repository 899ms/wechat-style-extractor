# 样格 · WeChat Style Extractor

![样格社交预览](public/介绍图.png)

从公众号文章中统计颜色、字号、行高、间距和内容组件，预览并复制文章排版。

样式统计是启发式识别；未识别项不显示，预览使用默认值。内联样式不能保证公众号编辑器完整保留原始排版。

## 当前版本

这是一个可交互的公众号样式提取工具，支持尝试解析公开的公众号文章链接，并提供：

- 公众号文章链接输入
- 视觉参数与组件规则展示
- 服务端抓取、HTML 安全清洗与样式归一化
- 标题、作者、颜色、字号、行高、间距与内容组件识别
- 保留正文原图、懒加载图片以及卡片中的 CSS 背景图
- 自动内联文章样式表，保留网格、定位、阴影、列表与表格等原始排版
- 手机端公众号文章预览
- 富文本复制到公众号编辑器
- 响应式桌面与移动端界面

出于安全考虑，解析接口只访问 `https://mp.weixin.qq.com`，并限制跳转域名、响应大小与读取时间。微信偶尔会对服务器访问展示安全验证页，此时页面会给出明确提示，可稍后重试。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

测试：

```bash
npm test
```

## 发布与恢复

GitHub 源码仓库和体验站托管仓库是独立的远端。更新 GitHub 不会自动更新体验站；每次发布前需按托管平台的实际发布流程更新原体验站。

发布新版前会在 GitHub 为当时的 `main` 创建 `backup/pre-upgrade-<date>` 标签。需要恢复时，以该标签创建恢复提交并按正常发布流程更新，不改写 Git 历史。
